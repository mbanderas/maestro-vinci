# Privacy notice

Last updated: August 12, 2026

Maestro: Vinci is a local skill package. The project does not operate a hosted design service, user-account system, analytics service, advertising system, telemetry endpoint, or prompt collection service.

## Local installation

The installer copies the packaged `vinci` skill to destinations selected on the user's computer. It does not send prompts, local files, designs, screenshots, or generated output to the maintainer.

Using npm or `npx` to download Vinci contacts the npm registry. Using GitHub to visit, clone, report an issue, or open a pull request contacts GitHub. Those services process information under their own privacy policies.

## Host and model processing

Vinci runs inside a host application and model provider selected by the user. That host or provider may process prompts, source material, images, repository content, generated output, metadata, and account information under its own terms and privacy policy.

The Vinci project does not receive that material unless a user separately submits it to the maintainer through a repository interaction or another chosen channel.

## External tools and sites

When a user directs Vinci or its host to open a site, control a browser, generate an image, render a document, or call another tool, the selected service may receive ordinary request, account, device, and network information. Vinci does not add a project-operated relay.

## Repository interactions

Public issues and pull requests are public. Do not submit confidential prompts, private source files, credentials, customer data, unpublished designs, or personal information through a public repository interaction.

## Retention and deletion

Vinci does not maintain a project-operated server containing user prompts or output. Users can delete local Vinci files with their operating system. Data held by npm, GitHub, a host, a model provider, or another selected service follows that third party's retention process.

Material changes to this notice will be published in this file.
